## 좌표·규칙 변환표 (칸 → 연속)
보드 좌표: 열 c=0..5, 행 r=0..7. **r=0이 카메라 쪽(플레이어)**. HTML 행 y는 `r = 7 - y`로 뒤집는다.
- 플레이어 배치 구역: r 0..3 (HTML y 4..7), 적 등장 구역: r 6..7 (HTML y 0..1).
- 배치 단계는 칸 스냅(드래그 → 칸), 전투는 연속 좌표. 웨이브 종료 시 시작 칸으로 복귀.

| HTML(칸) | Godot(연속, 단위=타일) |
|---|---|
| 맨해튼 사거리 R | 유클리드 거리 ≤ R + 0.15 (근접 R=1 → 1.15) |
| 이동 간격 m ms/칸 | 속도 `1000/m` 타일/초 (전사 2.5, 궁수 2.0, 마법사 1.25, 일반 적 0.83…) |
| 슬로우(간격 2배) | 공격 간격 2배, 속도 절반 |
| 1칸 넉백 / 밀기 | 반대 방향 knock 속도로 약 1타일 밀림, 보드 밖 클램프. 넉백 면역은 무시 |
| 스플래시 dist≤1 | 반경 1.2 원 |
| 관통 "바로 뒤 칸" | 공격자→대상 방향으로 대상 뒤 1타일 지점 반경 0.6 안의 적 1명 |
| 착지 주변(체비쇼프≤1) | 반경 1.4 원 |
| 2×2 거인 | 몸 반지름 2배, 모델 2배, 사거리는 몸 가장자리 기준 |
| 스프린터 8방향 2칸 | 0.76초마다 목표 쪽으로 2타일 대시(0.18초) |
| 닌자 점프 | 1.7초 쿨, 가장 먼 영웅 옆 빈자리로 포물선 도약 |
| 궁수 후퇴 | 가장 가까운 적 반대 방향으로 1타일 홉 |
| 콘(px 360, π/7) | 길이 6.4타일, 같은 각도 |
| 점유/막힘 | Toy Clash 분리력(separation)으로 대체. 히드라 시체는 막지 않음 |

## 시간
- 전투 전용 게임 시계 `now`(초)를 하나 둔다. 궁극기 조준 중에는 시계가 멈추고, 스턴·슬로우·가드·궁 쿨·히드라 부활·지연 타격 모두 이 시계 기준(원본 버그 10 수정).
- 지연 동작(명중 지연, 연쇄 번개 등)은 `create_timer` 대신 게임 시계 기반 스케줄러로 처리.
- 히트스톱은 Toy Clash의 `Engine.time_scale` 방식을 유지.

## 화면 구성 (세로 720×1280)
- 3D: 숲 디오라마 + 6×8 보드(앞쪽 4줄 = 내 진영 하이라이트). Toy Clash의 3D 벤치 트레이는 제거하고 그 자리에 인벤토리.
- 상단 HUD: 웨이브(서브웨이브), 남은 적, 골드, 시간의 결정, 배율, 기믹 안내.
- 유닛 머리 위: HP바(지연 바), 영웅은 마나바 + 레벨 배지 + SP 배지 + 궁 준비 링.
- 하단: 인벤토리 7×2 슬롯 패널, FIGHT! 버튼, 특성 트리 버튼.
- 팝업(Toy Clash 버튼·패널 스타일): 영웅 상세(스탯·장비·스킬 UP), 퍽 3택, 상인, 스킬북, 특성 트리, 게임오버, 튜토리얼 안내.

## 코드 구조 (GDScript)
```
scripts/
  main.gd        페이즈 상태머신(placement/spawning/battle/transition/gameover), 웨이브, 입력
  defs.gd        HTML 데이터 테이블(영웅/적/스킬/궁/아이템/전설/초월/유물/특수/퍽/특성 트리)
  stats.gd       효과 합산(스킬·스킬북·장비·퍽·유물·특성), 상한 처리
  actor.gd       전투 유닛(영웅/적 공용): 타겟팅, 자유 이동, 공격, 상태이상, 마나
  combat.gd      피해 공식, 온힛(치명/빙결/폭발/관통/넉백/교환/번개/추가공격), 처치 보상
  skills.gd      고유 스킬 3종, 궁극기 3종(조준 포함)
  waves.gd       서브웨이브 구성, 기믹 웨이브, 배율
  inventory.gd   인벤토리, 장착, 자동 합성, 판매, 드랍 테이블
  meta.gd        시간의 결정·특성 트리·전설 유물 저장(user://save.json)
  unit_model.gd  Toy Clash 치비 모델(+ 적 모델 추가)
  vfx.gd / sfx.gd / camera_rig.gd / mats.gd   Toy Clash 그대로 + 확장(냉기, 번개, 콘, 코인, 아이템 드랍)
  hud.gd + ui/*  HUD와 팝업
  world.gd       디오라마(6×8로 확장)
```
