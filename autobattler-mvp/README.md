# 3인 파티 로그라이크 오토배틀러 MVP

웹 기반(Vite + TypeScript + Canvas) 세로형 모바일 오토배틀러 프로토타입입니다.
사양서(`3party_autobattler_mvp_spec.md`)의 MVP 범위를 따라 구현되어 있습니다.

## 실행

```bash
cd autobattler-mvp
npm install
npm run dev
```

브라우저에서 자동으로 열리지 않으면 `http://localhost:5173` 접속.

빌드는 `npm run build`, 빌드 결과 미리보기는 `npm run preview`.

## 조작

자동 전투입니다. 직접 조작할 부분은 다음과 같습니다.

- **궁극기 버튼**(하단): 마나가 가득 차면 활성화. 누르면 발동.
- **인벤토리 아이템 탭**: 아이템 클릭 → 영웅 카드 클릭으로 수동 장착.
- **자동 장착**: 장비는 기본적으로 가장 적합한 영웅에게 자동으로 장착됩니다.
- **특성 선택**: 3 웨이브마다 3개 중 1개를 선택해 빌드를 강화합니다.

## 폴더 구조

```
src/
├─ core/        # 게임 루프, 상태, 카메라, 렌더러, 타입
├─ entities/    # Hero / Enemy / Projectile / Pickup
├─ systems/     # Wave / Drop / Item / Perk
├─ effects/     # 데미지 텍스트, 베기, 폭발
├─ ui/          # HUD, 하단 패널, 특성 오버레이, 시작/종료 화면
├─ styles/      # CSS
└─ main.ts      # 진입점
```

## 구현된 MVP 항목

- [x] 자동 전투 / AI 이동
- [x] 전사·궁수·마법사 3인 파티 (각 클래스 고유 공격/이동 패턴)
- [x] 웨이브/스테이지 시스템
- [x] 적: 일반 고블린 / 궁수 고블린 / 오크 탱커
- [x] 골드/장비 드랍 + 자동 흡수 연출
- [x] 4 등급 아이템 시스템 (일반/희귀/영웅/전설)
- [x] 수동·자동 장착
- [x] 3 웨이브마다 3-pick 로그라이크 특성
- [x] 마나 충전 → 궁극기 (전사: 광역 도발, 궁수: 화살 폭풍, 마법사: 메테오)
- [x] HUD: 골드, 스테이지/웨이브 게이지, 영웅 HP/MP, 장비 슬롯
- [x] 연출: 피격 플래시, 히트 스케일, 넉백, 크리티컬 텍스트, 폭발, 잔상, 화면 흔들림, 궁극기 강조
