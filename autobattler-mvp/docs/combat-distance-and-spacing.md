# 전투 거리·간격 제어 — 기술 정리 (이식용)

이 문서는 **autobattler-mvp**에서 영웅·적이 서로 **거리를 줄이거나 벌리는 방식**을, 다른 게임에 옮길 수 있도록 풀어 쓴 것이다.  
구현 참조: `src/entities/Hero.ts` (`moveToward`, `applyAnchoring`), `src/entities/Enemy.ts` (이동·돌진·원거리), `src/core/Types.ts` (맵 경계 상수).

---

## 1. 기본 좌표·적분 모델

- **2D 위치** `pos = (x, y)`, **속도** `vel = (vx, vy)` (단위: 월드 좌표 / 초).
- 매 프레임 `dt`(초)마다:

  `pos += (vel + knockback) * dt`

  이후 **맵 경계로 클램프**. 프레임 끝에 `vel`을 **0으로 리셋**한다 (매 틱 의도 속도만 다시 계산하는 **일회성 속도** 패턴).

- **넉백** `knockback`은 별도 벡터로 두고, `Entity.baseUpdate`에서 시간에 따라 감쇠한다. 이동 의도와 합쳐져 순간적으로 거리가 벌어진다.

**이식 시 포인트:** “목표 속도를 매 프레임 완전히 새로 쓸지” vs “가속도로 스무딩할지”는 게임 취향이다. 이 프로젝트는 **스냅형(매 틱 vel 재설정 + 끝에 0)** 이라 구현이 단순하다.

---

## 2. 공통 기하: 타깃까지 벡터

타깃 `T`, 자신 `P`:

- `dx = T.x - P.x`, `dy = T.y - P.y`
- `dist = hypot(dx, dy)` (0 나눗셈 방지: `dist || 1`)
- **정규화 방향**: `ux = dx/dist`, `uy = dy/dist`

**접근(거리 줄이기):** `vel = (ux, uy) * speed`  
**후퇴(거리 벌리기):** `vel = (-ux, -uy) * speed` (또는 `speed * 후퇴계수`)

---

## 3. 히스테리시스 밴드 (떨림 방지)

원거리 유닛은 “딱 한 거리”가 아니라 **내부·외부 두 임계값**으로 띠를 두는 것이 일반적이다.

예: 이상 거리 `desired`, 허용 오차 `bandInner`, `bandOuter`

| 구간 | 행동 |
|------|------|
| `dist < desired - bandInner` | 너무 가깝다 → **후퇴** |
| `dist > desired + bandOuter` | 너무 멀다 → **접근** |
| 그 사이 | **이동 최소화** 또는 미세 움직임만 |

**영웅 궁수 (`Hero.ts`):** `desired = preferredDistance`, 대략 `desired ± 8`.  
**적 고블린 궁수 / 샤먼 (`Enemy.ts`):** `desired ± 6`, 후퇴 시 y속도에 `0.55` 배율로 **비등방** 후퇴(덜 빠르게 세로로 벌림).

**이식 시 포인트:** 밴드가 없으면 경계에서 **진동**(한 프레임 접근→다음 프레임 후퇴 반복)이 잘 난다.

---

## 4. 근접: “사거리 안이면 멈춤”

**전사:** `dist > attackRange - 2` 일 때만 추적 속도 부여. 그 안이면 `vel = 0` (추가 이동 없음).

**일부 적(고블린·오크·브루트·차저 비돌진):** `dist > attackRange - 2` 일 때만 적을 향해 이동.

**의미:** 거리 제어가 **이동 AI**가 아니라 **공격 판정**과 결합된다. “맞을 수 있는 최대한 가까이”에서 멈춘다.

---

## 5. 원거리 키팅(대칭 패턴)

**아군 궁수**와 **적 고블린 궁수/샤먼**은 같은 패턴 계열이다.

- 너무 가까우면: `-(ux, uy) * speed`, 필요 시 한 축만 약하게 (`uy * 0.6` 등).
- 너무 멀면: `(ux, uy) * speed * 0.6~0.65` (접근을 **느리게** 해 과추적 완화).
- 적당 거리: 궁수는 `sin(time * ω + id) * 12` 정도로 **y만 미세 위빙** (정지감 완화).

**이식 시 포인트:** “후퇴 = 접근의 반대”에 **축별 스케일**을 주면 슬라이딩 느낌·세로 키트가 자연스럽다.

---

## 6. 마법사(영웅): 거리 + **진영 Y 고정**

- X: `dist < desired - 10` → 뒤로, `dist > desired + 30` → 앞으로 (계수 `0.4`로 느리게).
- Y: 별도 목표 높이 `targetY = BATTLE_BOTTOM - 30` 을 두고,  
  `vel.y = sign(targetY - pos.y) * min(speed * 0.5, abs(dyHome) * 4)`  
  → 아군 진영(아래)으로 **수직 정렬**을 우선한다.

**의미:** “적과의 거리”와 “팀 포지션”을 **분리 목표**로 둔다. 다른 게임에서는 안전 지대·하이그라운드·포인트 점령 좌표로 치환 가능하다.

---

## 7. 적 특수: 돌진(버스트 오버슈트)

**차저(`charger`):**

- 평소: 근접과 같이 `dist > attackRange - 2` 이면 추적.
- 쿨다운이 끝나고 `38 < dist < 210` 이면 짧은 시간 `chargeBurstT` 동안  
  **동일 방향으로 `moveSpeed * 2.35`** — 일시적으로 목표를 **오버슈트**할 수 있다.

**이식 시 포인트:** “거리 줄이기”를 **상시**가 아니라 **스킬 슬롯**처럼 쓰면 리듬이 생긴다.

---

## 8. 적 타깃 선택으로 간접적 거리 정책

**브루트:** 가까운 영웅이 아니라 **궁수·마법사** 우선(일정 거리 `220` 안에서).  
→ 탱커가 아닌 쪽으로 유닛이 움직이며, 파티 전체와의 **상대적 거리 분포**가 바뀐다.

**이식 시 포인트:** 이동 법칙은 같아도 **타깃 필터**만 바꿔도 “거리 유지 전략”이 달라 보인다.

---

## 9. 스티어링 합성: 홈 닻 + 벽 + 아군 분리

`applyAnchoring`은 `moveToward` **이후**에 가속도 성격의 벡터 `ax, ay`를 `vel`에 **가산**한다.

1. **홈 닻:** `(home - pos)` 방향으로 크기 `min(moveSpeed * 0.32, distHome * 0.9)` (멀수록 강하지만 상한).
2. **벽 반발:** 가장자리 `margin` 안에 있으면 안쪽으로 `push * t²` (거의 벽일수록 강함).
3. **아군 분리:** 반경 `sepR` 안 다른 영웅에게서 밀어내기, 가중치 `(1 - d/sepR)²`.
4. **속도 캡:** `hypot(vel) <= moveSpeed * 1.2` 로 정규화.

**이식 시 포인트:** 이것은 전형적인 **스티어링 행동 합성(seek + boundary + separation)** 이다. RTS·MOBA·오토배틀러에서 재사용 빈도가 높다.

---

## 10. 보스 대시(텔레그래프 후 순간 이동)

보스 스킬 중 하나는 **정규화 방향 * 고정 거리 `dash`** 만큼 `pos`를 즉시 이동시키고, 근접 여부로 피해 판정한다.  
(프레임 간 `vel` 적분이 아닌 **스냅 이동**)

**이식 시 포인트:** “거리 줄이기”를 연속 이동이 아니라 **디스크리트 점프**로 표현할 수 있다.

---

## 11. 다른 게임에 적용할 때 체크리스트

1. **거리 판단**은 `dist` 하나인지, X/Y 분리인지 정할 것.
2. 원거리는 **히스테리시스 밴드** + (선택) **비등방 속도**.
3. 근접은 **attackRange - ε** 로 이동 중단할지, 별도 “착취 거리”를 둘지.
4. 이동과 공격을 같은 틱에 쓸 때 **사거리 + 소량 여유**(`+2`, `+4`)로 공격 허용 흔들림 방지.
5. 맵 밖 밀림은 **클램프**; 모서리 끼임은 **반발 필드** 또는 **홈 시크**로 완화.
6. 여러 AI가 겹치면 **separation** 또는 **슬롯 포인트** 할당을 고려.
7. 넉백·돌진은 **일시적 고속** 또는 **pos 점프**로 구분해 디자인한다.

---

## 12. 참고할 만한 외부 게임 디자인 키워드 (이 프로젝트와의 대응)

| 키워드 | 이 MVP에서의 대응 |
|--------|-------------------|
| Kiting / spacing | 궁수·고블린 궁수의 desired ± 밴드 |
| Leash / soft tether | `applyAnchoring` 홈 닻 |
| Body block / separation | 아군 간 거리 밀어내기 |
| Charge / gap close | 차저 돌진 배율 |
| Tank prefers ranged | 브루트 타깃 필터 |
| Boss telegraph + rush | 보스 대시 텔레그래프 후 pos 스냅 |
