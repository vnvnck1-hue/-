# 특수 장비 성장 개편 계획 (등급 사다리 편입 + 영웅당 1개 제한)

> 상태: **기획 확정, 구현 대기 — 시급** (2026-10-13 작성)
> 대상: `godot/scripts/defs.gd` (LEGENDARY / TRANSCENDENT), `gear.gd` (`era_power`, `slot_cap`), `stats.gd` (`entry_stats`, `has_effect`),
> `inventory.gd` (`era_scale`, `merge_key`, `merge_result`, `equip`), `meta.gd` (`merge_all`, `_merge_once`, 세이브 로드), `main.gd` (`equip_item`, 상점 가격),
> `gear_screen.gd` / `hud_panels.gd` (상세 카드 UI)

## 문제

공허의 닻·천둥의 심장 같은 특수 장비(LEGENDARY)는 고유 효과는 좋지만, 기본 능력치가 더 좋은 일반 장비를 얻으면 장착할 이유가 사라진다.

원인:

| 원인 | 위치 | 내용 |
|---|---|---|
| 일반 장비는 끝없이 성장 | `gear.gd` `Gear.def()` | 등급당 고정 수치 ×1.75(`GROWTH`), 9등급부터 초월 ★로 무한 |
| 특수 장비 성장은 획득 시점에 굳음 | `gear.gd` `era_power`, `inventory.gd` `era_scale` | 주운 지역 기준 pw가 정해지면 이후로 안 커짐 |
| % 수치는 성장 안 함 | `stats.gd` `entry_stats` | pw는 atk/hp만 곱함 |
| 슬롯 강화 레벨 손해 | `gear.gd` `slot_cap` | 정의된 tier(5/6)로 상한 → pw 무시, 고등급 슬롯 레벨이 깎임 |
| 기준값 자체가 약함 | `defs.gd` LEGENDARY | 천둥의 심장(공격 15, 치명 10%) < 영웅 폭풍의 반지(공격 20, 치명 10%, 공속 40%) |

## 목표

- 특수 장비가 **일반 장비와 함께 등급을 따라 올라갈 수 있게** 한다.
- 그렇다고 **모든 슬롯에 특수 장비를 끼는 것이 정석이 되지 않게** 한다 — 일반 장비의 가치를 유지한다.
- 플레이어의 선택이 "특수 장비를 낄까 말까" → **"재료를 어디에 쓸까 / 어느 영웅에게 어떤 효과를 줄까"** 로 바뀐다.

## 설계

### 1. 기준값 재조정 (선행)

- 각 특수 장비의 기준 능력치를 **같은 슬롯·같은 등급 일반 장비의 약 90~95%** 수준으로 다시 맞춘다.
  - 예: 천둥의 심장 5등급 기준 공격 약 30 + 공속 소량 (현재 공격 15).
- % 수치(치명·공속·받는 피해 감소 등)는 기준값을 그대로 두고 **성장시키지 않는다** — 받는 피해 상한(`CAP_REDUCE = 0.9`) 등이 깨지지 않게.
- 효과 크기(넉백 거리, 번개 80% 등)는 **키우지 않는다**. 번개는 이미 공격 피해에 비례한다.

### 2. 등급 필드 (pw 대체)

- 특수 장비 인스턴스에 `grade` 필드를 둔다. pw는 폐지하고 등급으로 대체.
- 획득 시 등급 = 기존 pw 공식과 동일한 기준 (`max(tier, base_grade(k) + 1)` — 현재 era_power와 같은 결과).
- 능력치: `atk/hp = 기준값 × GROWTH^(grade - tier)`, % 수치는 고정.
- 상점·판매 가격의 `pw` 곱셈은 `GROWTH^(grade - tier)`로 교체.

### 3. 특수 장비 강화 (별도 창구 — 자동 합성에 넣지 않음)

- **특수 장비 1 + 같은 슬롯·같은 등급 일반 장비 2 → 특수 장비 등급 +1** (효과 유지).
- 로비의 [합성] 버튼(`Meta.merge_all`)은 지금처럼 **일반 장비끼리만** 합친다. 특수 장비는 재료로도 결과물로도 끼지 않는다.
- 특수 장비 상세 카드에 **[강화] 버튼**:
  - 누르면 재료 2개와 강화 후 능력치를 미리 보여 주고 확인 후 진행.
  - 재료 자동 추천: 장착하지 않은 같은 슬롯·같은 등급 중 능력치가 가장 낮은 것. 사용자가 교체 가능.
  - 재료 부족 시 비활성 + "6등급 장신구 2개 필요 (보유 1)" 표시.
- 자동 합성으로 하지 않는 이유: 재료 충돌(일반 합성 vs 특수 강화), 되돌릴 수 없음, "재료를 어디에 쓸지"라는 핵심 선택이 사라짐.

### 4. 초월 합성 재정의

- 같은 특수 장비 3개 → **등급 유지 + 효과 1개 추가** (예: 번개 + 처치 시 마나 충전).
- 결과 등급 = 재료 중 최고 등급.
- 이것도 특수 장비 상세 카드에서 미리보기 후 확인하는 방식으로 처리.
- TRANSCENDENT 표의 능력치를 정리해야 하므로 **범위가 큼 → 1~3·5·6 이후 별도 단계로 진행 가능**.

### 5. 슬롯 강화 상한

- `slot_cap`이 정의 tier가 아닌 **인스턴스 grade** 를 기준으로 계산되게 한다. (7등급 특수 장비 → 70레벨까지 적용)

### 6. 영웅당 특수 장비 1개 제한

- 영웅마다 무기·방어구·장신구 중 **특수 장비는 1개만** 장착 가능. 나머지 두 칸은 항상 일반 장비 → 일반 장비 가치 유지.
- 파티 전체 효과는 최대 3개 → 효과 간 순환(마나 공유 × 처치 시 마나 등) 폭주도 자연 제한.
- 개수 제한이 쏠림을 막으므로 1번의 능력치 배율을 후하게(90~95%) 줄 수 있다.
- 동작:
  - 같은 영웅에게 두 번째 특수 장비를 끼려 하면 "특수 장비는 영웅당 1개" 안내 + 기존 것과 교체할지 확인.
  - 런 도중 획득·자동 장착 경로(`Inventory.equip`, `main.equip_item`)가 **같은 검사 함수**를 쓰게 한다.
- 전설의 왕관(crown)은 효과가 없는 능력치 장신구이므로 **특수 장비로 치지 않는다**.

### 7. 알림

- 강화 가능한 특수 장비가 있으면 장비 화면·해당 카드에 빨간 점 (`merge_ready`와 같은 방식).
- [합성] 실행 시, 특수 장비 강화 재료로 쓸 수 있던 장비가 포함되면 한 줄 경고 + "그 장비는 빼고 합성" 선택지.

### 8. 세이브 변환

- 기존 pw → `grade = tier + round(log(pw) / log(GROWTH))` (pw = 1.75^(초과 등급) 이므로 정확히 떨어짐). 체감 능력치는 그대로.
- 한 영웅이 특수 장비를 2개 이상 끼고 있으면 최고 등급 1개만 남기고 나머지는 보관함으로 이동 + 안내.

## 예상 시나리오

| 상황 | 현재 | 변경 후 |
|---|---|---|
| 2지역에서 천둥의 심장 획득 → 5지역 | 공격 15로 굳음, 반지 신화(공격 약 61)에 밀려 버려짐 | 장신구 2개로 6등급 강화, 반지와 등급을 맞춰 계속 사용 가능 |
| 7지역에서 획득 | 처음부터 7등급 상당 | 동일 (7등급으로 시작) |
| 같은 특수 장비 3개 | 초월(고정 수치) | 등급 유지 + 효과 추가. 단 드랍률 3%·5종이라 매우 드묾 |
| 공허의 닻 | 체력/공격 pw 반영, 받는 피해 -42% | 체력/공격만 등급 성장, -42% 고정 → 상한 안전 |
| 슬롯 강화 70레벨 + 특수 장비 | 50레벨로 잘림 | 7등급이면 70레벨 전부 적용 |
| 특수 장비 4개 이상 보유 | 슬롯마다 다 낄 수 있음 | 영웅당 1개 → 3개만 사용, 나머지는 교체 후보 / 초월 재료 |

## 예상 부작용 / 남은 결정

- 장신구·방어구 재료 수요 증가 → 해당 슬롯 일반 합성이 느려짐 (의도된 트레이드오프).
- "모은 특수 장비를 다 못 쓴다"는 불만 → 후한 능력치 배율 + 초월 재료 용도로 완화.
- **미결정**: 같은 특수 장비 2개째를 1개째의 성장 재료로 쓸 수 있게 할지 (3개 모으기가 너무 드물어서).
- 실제 플레이 후 능력치 배율(90~95%) 조정 필요.

## 구현 순서

1. 기준값 재조정 (`defs.gd` LEGENDARY)
2. 등급 필드 도입 + pw 대체 (`inventory.gd`, `stats.gd`, `gear.gd`, 상점 가격)
3. 특수 장비 강화 창구 + [합성]에서 특수 장비 제외 (`meta.gd`, `gear_screen.gd`, `hud_panels.gd`)
4. `slot_cap` 인스턴스 등급 기준
5. 영웅당 1개 제한 (장착 검사 공용 함수)
6. 세이브 변환
7. 알림 (빨간 점, 합성 경고)
8. (별도 단계) 초월 합성 재정의 + TRANSCENDENT 정리

완료 후 `godot/tools/build_exe.py`로 TrioChess.exe 재빌드.
