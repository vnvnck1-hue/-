# 스킬북 연출 경량화 계획 (플로팅 카드 뒤집기)

> 상태: **계획만 작성, 미구현** (2026-10-13)
> 대상: `godot/scripts/skill_gacha.gd` (SkillGacha), 호출부 `godot/scripts/main.gd` `use_book()`

## 목표

지금의 전체화면 룰렛(셰이더 배경 + 슬롯 릴 3개 + 대형 연출)을 **필드 위에 떠 있는 가벼운 카드 연출**로 바꾼다.

- 배경을 가리지 않는다 — 뒤에 필드가 보인다 (얇은 반투명 딤만).
- 전투는 지금처럼 멈춘다 (`get_tree().paused = true`, 닫힐 때 원래 상태로 복구 — 기존 로직 유지).
- 스킬북에서 카드 3장이 하늘로 빠르게 치솟고 → 화면 중앙에 3장이 나열되며 → 순차적으로 뒤집혀 어떤 스킬인지 공개.
- **등급이 한눈에 구분**되어야 한다.

## 현재 구조 (바꿀 부분)

| 단계 | 현재 | 변경 |
|---|---|---|
| 배경 | `ChestGacha.SHADER` 전체화면 배경, 회전 레이 | 제거. `ColorRect` 딤(α≈0.35)만, 필드 보임 |
| 인트로 | 책이 위에서 떨어짐, "스킬 뽑기" 타이틀, 등급 플레이트, 확률 칩 | 제거. 책은 **인벤토리 슬롯 위치**에서 등장 |
| 뽑기 | 슬롯 릴 3개 회전 → 하나씩 정지 (`Reel` 클래스, `_tick`) | 카드 뒷면 3장 → 순차 뒤집기 |
| 공개 | 등급별 링/스파크/플래시/레이/배너 | 유지하되 카드 주변 국소 연출로 축소 (아래 표) |
| 선택 | 카드 탭 / 슬롯 교체 / 건너뛰기 | **그대로 유지** (`_ready_to_pick`, `_pick`, `_ask_slot`, `_finish`, `_close`) |
| 음악 | `Music.play("gacha")` 로 교체 | 교체하지 않음 (가볍게) — 효과음만 |

## 연출 타임라인 (기본 속도, 탭하면 빨리감기)

1. **책 등장 (0.0–0.25s)** — `use_book()`에서 책의 슬롯 화면 좌표(`hud.panels.slot_center(inventory.find(e))`)를 erase 전에 구해 `SkillGacha.from_pos`로 넘긴다. 그 자리에 `ItemIcon({"kind":"skillbook","grade":g})`이 팝업 → 살짝 부풀며 떨림, 책 등급색 링.
2. **치솟기 (0.25–0.55s)** — 책에서 작은 카드 뒷면 3장(scale≈0.4)이 0.05s 간격으로 화면 위 밖(y < -200)까지 빠르게 솟구침. `TRANS_QUAD EASE_IN`, 약간의 회전/좌우 퍼짐, 꼬리 잔상(반투명 사본 1~2개), `whoosh`. 책은 축소·페이드아웃.
3. **나열 (0.55–0.95s)** — 3장이 위에서 내려와 화면 중앙(세로 중앙 약간 위)에 가로 정렬. `TRANS_BACK EASE_OUT`, 착지 시 회전 0으로 정착 + 작은 `thud`.
4. **순차 뒤집기 (카드당 ≈0.35s + 등급 연출)** — 왼쪽부터:
   - 예고(등급별, 아래 표): 뒷면이 등급색으로 떨리며 빛남 — 높은 등급일수록 길게.
   - 뒤집기: `scale.x` 1→0 (0.12s) → 뒷면을 앞면(`_face(id)`)으로 교체 → 0→1 (오버슈트).
   - 공개 연출 후 `_status_tag` (NEW / Lv.n→n+1 / 교체) 부착.
5. **선택** — 기존 `_ready_to_pick()` 그대로. 힌트/건너뛰기 버튼 위치만 카드 기준으로 재배치.

## 등급별 구분 (핵심)

카드 앞면은 기존 `_face()` 그대로 (백판·테두리·등급 라벨이 등급색). 그 위에 다음을 얹는다.

| 등급 | 뒤집기 전 예고 | 공개 연출 | 공개 후 유지 |
|---|---|---|---|
| 일반 | 없음 | 흰 링 + `pop` | 없음 |
| 희귀 (파랑) | 0.15s 파란 테두리 깜빡 | 파란 링 + 스파크 8개 + "희귀!" 스탬프, `chime` | 파란 외곽선 |
| 영웅 (보라) | 0.4s 보라 글로우 + 떨림 2박 | 화면 약한 플래시(α≈0.35) + 카드 뒤 보라 레이 + 오라 + 흔들림 6px + "영웅!" 스탬프, `boom`+`chime`+`sparkle` | 보라 레이 회전 + 오라 맥동 |
| 전설 (금) | 0.7s 금빛 글로우 + 떨림 3박 + 딤 살짝 어두워짐 | 금빛 플래시(α≈0.6) + 큰 금 레이 + 오라 + 반복 샤인 + 흔들림 12px + 컨페티 + "전설 스킬!" 배너, `fanfare` | 금 레이 + 샤인, 나머지 카드는 살짝 어둡게 |

- 등급색은 `Hud._vivid(Defs.RARITY_COL[Defs.book_rarity(sg)])` 사용 (기존과 동일).
- 연출은 화면 전체가 아니라 **카드 주변**에 한정 (플래시만 예외, 그래도 약하게).
- 뒷면 디자인: 짙은 남색 카드 + 금테 + 가운데 "?" — 등급 정보는 뒤집기 전 예고에서만 드러남(기대감).

## 코드 변경 범위

- `skill_gacha.gd`
  - 삭제: 셰이더 배경(`_bg*`, `_set_bg`, `_apply_bg`, `BG_GOLD`), `Reel` 클래스, `_random_face`, `_face_pool`, `_tick`, `_land`, `_suspense`, 인트로의 타이틀/플레이트/확률칩.
  - 추가: `var from_pos: Vector2`, `_card_back()`, `_launch()`(치솟기), `_line_up()`(나열), `_flip(i)`(예고+뒤집기), `_tease(i, sg)`.
  - `_reveal(i, id, sg)`는 유지하되 배경 전환/전체 레이 제거, 강도 하향.
  - 테스트 호환을 위해 `offers`, `state`, `_faces`, `_frames`, `_pick`, `_finish`, `tap()` 이름 유지.
- `main.gd` `use_book()` — 슬롯 좌표 계산해 `sg.from_pos` 전달, `Music.play("gacha")` 및 닫힐 때 음악 복귀 호출 제거.
- `march_main.gd` `_test_books()` — 스크린샷 태그 갱신 (`books_gacha_spin` → `books_gacha_launch` 등). `sg._faces` 대기 로직은 그대로 동작.
- `defs.gd:131`, `main.gd:1395` 주석의 "reels" 표현 갱신.
