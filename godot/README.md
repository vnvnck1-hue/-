# TRIO CHESS (Godot 포팅)

트리오 체스 HTML 프로토타입의 게임 시스템과 기획을 **Toy Clash의 외형과 게임 필**로 옮긴 Godot 4.7 프로젝트입니다.
모델, 텍스처, 아이콘, 효과음, 배경음악은 Toy Clash처럼 모두 코드로 생성하며 외부 에셋은 쓰지 않습니다.

- 기획 원천: [../docs/html_game_spec.md](../docs/html_game_spec.md) (HTML 규칙·수치 정리)
- 포팅 계획과 결정 사항: [../docs/godot_port_plan.md](../docs/godot_port_plan.md)

## 실행
- **게임 실행 파일은 저장소 최상위의 `TrioChess.exe`(`트리오트러블\TrioChess.exe`) 하나뿐입니다.** 더블클릭하면 됩니다(게임 데이터 내장, 옆에 다른 파일 불필요).
- 코드를 고친 뒤 실행 파일 다시 만들기(최상위 `TrioChess.exe`를 덮어씀, `godot/build/`의 예전 빌드는 지움):
  ```bash
  python tools/build_exe.py
  ```
  - Windows export 템플릿이 없어서, 에디터로 게임 데이터(pck)를 뽑은 뒤 일반 Godot 4.7.2 실행 파일 끝에 붙여 단일 exe로 만듭니다.
- 개발 중 바로 확인(빌드 없이): Godot 4.7.2(winget `GodotEngine.GodotEngine.Mono`)로 이 폴더를 열고 F5, 또는
  ```bash
  "$HOME/AppData/Local/Microsoft/WinGet/Packages/GodotEngine.GodotEngine.Mono_Microsoft.Winget.Source_8wekyb3d8bbwe/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64.exe" --path .
  ```

## 모바일에서 플레이 (웹 빌드)
화면이 세로(720×1280)이고 조작은 터치(마우스 에뮬레이션)로 모두 되므로, 웹으로 내보내 폰 브라우저로 접속합니다.
웹은 Compatibility 렌더러(WebGL 2)로 돌아서 PC판보다 그림자·후처리가 단순하고, 첫 게임 진입 때 셰이더 컴파일로 몇 초간 회색 화면이 보일 수 있습니다.
- 웹 export에는 Mono가 아닌 **일반 Godot 4.7.2**와 export 템플릿(`%APPDATA%\Godot\export_templates\4.7.2.stable\`)이 필요합니다.
  ```bash
  "<일반 Godot 4.7.2 폴더>/Godot_v4.7.2-stable_win64_console.exe" --headless --path . --export-release "Web" build/web/index.html
  ```
- PC에서 서버 실행(같은 Wi-Fi의 폰에서 접속): `python -m http.server 8060 --directory build/web` → 폰에서 `http://<PC의 IPv4>:8060`
  - Windows 방화벽이 막으면 관리자 PowerShell에서 한 번 허용: `New-NetFirewallRule -DisplayName "TrioChess Web 8060" -Direction Inbound -Protocol TCP -LocalPort 8060 -Action Allow -Profile Any`
- 풀스크린: 폰 브라우저 메뉴의 **홈 화면에 추가**로 설치하면 주소창 없이 세로 고정으로 실행됩니다(PWA, 오프라인 캐시는 HTTPS에서만 동작).
- 게임 중 로비 복귀는 게임 오버 창의 [로비로] 버튼이나 새로고침으로 합니다(모바일엔 Esc 키가 없음).

## 로비와 모드
실행하면 로비가 먼저 나옵니다. 위쪽에는 영웅 3명이 선 회전 무대가, 아래쪽에는 모드 카드와 최고 기록이 있습니다.
- 위쪽에는 보유 재화(골드 · 강화석 · 시간의 결정)가, 아래쪽에는 [장비] 버튼, **원정** 카드, **끝없는 행군** 카드가 있습니다.
- **원정**: 행군 길의 지역 하나가 챕터 하나입니다(챕터 c = 무리 c×10+1 ~ c×10+10). ◀ ▶로 열린 챕터를 고르고 [출발]을 누릅니다.
  중간 보스를 쓰러뜨리면 원정 성공이고 다음 챕터가 열립니다. 첫 클리어 보너스는 골드 150×챕터, 강화석 8×챕터입니다.
  챕터는 그 구간에 맞는 영웅 레벨과 일반 스킬북으로 시작합니다(`CHAPTER_LEVEL` = 1/5/8/11/14/17, `CHAPTER_BOOKS` = 0/1/2/2/2/2권, 끝없는 행군에서 그 무리쯤 도달하는 상태).
- **끝없는 행군**: 1무리부터 전멸할 때까지 이어지며, 최고 기록(`best`)이 남습니다.
- 클래식 6×8 보드 모드는 로비에서 내렸습니다(코드는 남아 있음).
- 게임 중 `Esc`로 나가면 그때까지 얻은 것이 정산되어 보관됩니다.

## 성장 메타 (Habby식, `docs/habby_meta_plan.md`)
**장비는 영구, 스킬은 판 안에서 득템.** 판(원정 한 번 / 끝없는 행군 한 번)이 끝나면 정산 창이 뜹니다.
| | 판 안 (끝나면 사라짐) | 판 밖 (영구, `Meta`) |
|---|---|---|
| 강해지는 것 | 스킬북으로 배운 스킬, 특성(룰렛), 영웅 레벨 | 장비(로비 합성) + 장비 칸 레벨(강화) |
| 줍는 것 | 스킬북, 강화석, 골드, 상자, 장비(드묾) | 정산 때 장비 → 보관함, 골드·강화석 → 은행 |

- 필드에서 줍는 강화석은 가방으로 가지 않고 동전처럼 화면 위쪽 강화석 칸으로 날아 들어갑니다(`Hud.fly_stone`, `Main.fly_stones`). 상자 보상의 강화석도 같습니다.

- **스킬**(`Defs.SKILL_BOOKS`): 직업마다 9종, 4등급입니다.
  - 일반: 기본 패시브. 희귀: 복합 패시브. 영웅: 고유 스킬 강화(피해·화살 수·기절·빙결). 전설: 궁극기 강화(피해·쿨타임·튕김).
- **스킬북**은 스킬 하나가 아니라 **등급**(일반·희귀·영웅·전설)만 가진 책이고, 어느 영웅에게나 씁니다.
  - 전투 중 몬스터 드롭(대장·중간 보스는 한 등급 위), 상자, 상인에게서 얻습니다. 뒤 지역일수록 높은 등급이 나옵니다.
  - **가방 자동 합성**: 같은 등급 3권이 모이면 가방에서 바로 한 등급 위 책 1권으로 합쳐집니다(일반→희귀→영웅→전설, 연쇄 합성).
    가방이 가득 차 있어도 합성을 완성하는 책은 들어옵니다. 연출은 세 권이 칸에서 떠올라 한 칸으로 모여 번쩍이고 새 책이 튀어나옵니다(`HudPanels.play_merge`).
  - 가방에서 눌러 **[사용]**하면 **스킬 뽑기 룰렛**(`SkillGacha`, 콩콩던전 스킬 뽑기식)이 열립니다. 슬롯 3칸이 함께 촤르르륵 돌다가
    하나씩 차례로 멈추며 스킬이 나오고, 그중 하나를 골라 배웁니다(이미 아는 스킬이면 레벨 업, Lv.5까지). [건너뛰기]도 있습니다.
  - **책 등급 = 고점**: 슬롯에는 책 등급 이하의 스킬만 나옵니다. 칸마다 스킬 등급 확률(`Defs.BOOK_ROLL`):
    일반 책 일반 100% · 희귀 책 일반 55 / 희귀 45 · 영웅 책 30 / 40 / 영웅 30 · 전설 책 10 / 20 / 35 / 전설 35%.
    낮은 책을 바로 쓰면 뽑기 횟수가 많고, 모아서 합성하면 횟수는 줄지만 높은 등급 스킬이 열립니다.
  - 등장 연출은 스킬 등급이 높을수록 커집니다. 카드 백판·테두리는 그 스킬의 등급색입니다.
    일반: 팝 / 희귀: 파란 고리·반짝이·"희귀!" / 영웅: 화면 번쩍·보라 회전 빛줄기·흔들림·"영웅!" 도장 /
    전설: 멈추기 전 오래 감속하며 칸 테두리가 두근거리고 화면이 어두워짐 → 화이트아웃·금빛 배경·거대 빛줄기·강한 흔들림·"전설 스킬!" 배너·폭죽, 다른 카드는 어두워지고 전설 카드에 빛이 계속 스칩니다.
    영웅·전설이 멈출 칸 바로 앞에는 같은 등급 카드가 스쳐 지나갑니다(아깝다 연출). 돌고 있을 때 화면을 탭하면 남은 칸이 바로 멈춥니다.
  - 스킬 칸은 영웅마다 4칸입니다. 칸이 가득 찬 영웅의 새 스킬(카드에 "교체" 표시)을 고르면 잊을 스킬을 고르는 창이 뜹니다([뒤로]로 다른 카드 선택 가능).
  - 남은 책은 판이 끝날 때 강화석으로 바뀝니다(일반 1 / 희귀 3 / 영웅 6 / 전설 12).
  - 영웅 상태 줄의 보라 배지 "+N"은 가방의 스킬북 수입니다. 스킬 포인트(SP)는 없앴습니다.
- **장비**:
  - 판 안에서는 합성하지 않습니다. 일반 처치에서 장비가 나올 확률은 예전의 12%이고, 중간 보스는 1개를 확정으로 줍니다.
  - 가방이 차면 장비는 보관함으로 바로 갑니다(사라지지 않음).
  - 착용과 가방 상태는 바뀔 때마다 저장되므로 중간에 꺼도 잃지 않습니다(`Meta.sync_run`).
- **로비 [장비]**(`scripts/gear_screen.gd`):
  - 영웅 탭과 무기·방어구·장신구 칸이 있습니다. 칸의 장비를 누르면 해제됩니다.
  - **칸 강화**: 골드 + 강화석으로 올립니다(`Gear.upgrade_cost`). 레벨은 칸에 붙어서, 그 칸에 낀 장비(판 중 주운 것 포함)가 모두 보너스를 받습니다.
    - 무기 칸은 공격력 +3/Lv, 방어구 칸은 체력 +22/Lv, 장신구 칸은 공격력 +1.5와 체력 +10/Lv입니다.
    - 적용되는 레벨의 상한은 낀 장비 등급 × 10입니다.
  - **보관함**: 장비를 눌러 [장착]하거나 [판매]합니다. **[모두 합성]**은 같은 부위·같은 등급 3개를 다음 등급 1개로 만듭니다(예전 가방 규칙과 같음).
- **로비 [유물]**(`scripts/relic_screen.gd`): 유물은 더 이상 판 중 가방에 들고 다니지 않습니다.
  - 판에서 주운 유물은 곧바로 로비 유물 보관함으로 갑니다(토스트로 알림, `Meta.add_relic`).
  - 장착 칸 3개(`Defs.RELIC_SLOTS`)에 낀 유물이 모든 판에서 파티 전체에 적용됩니다(`game.relics`). 같은 유물은 두 칸에 낄 수 없고, 더 높은 ★를 장착하면 그 칸과 바뀝니다.
  - **★ 합성**: 같은 유물·같은 ★ 3개 → 다음 ★ 1개(최대 ★5). ★마다 기본 효과의 +25%(`Defs.relic_mult`, ★5 = 200%). 흡혈은 합쳐서 최대 35%(`Stats.CAP_LIFESTEAL`). 보관함 칸에 `n/3` 진행도가 보입니다.
  - 판 중에는 [특성] 목록 아래에 장착 유물과 ★별 효과가 함께 보입니다.
  - 예전 저장(`relics` 키 목록)은 처음 불러올 때 장착 칸에 끼워지고, 중복분은 보관함으로 갑니다.
- **합성 연출**(`scripts/merge_fx.gd`, 장비·유물 공용): 재료 3개가 삼각형으로 튀어나옴 → 점점 빨리 돌며 모여들고 광선·흔들림·불꽃 꼬리가 차오름 →
  짧은 히트스톱 뒤 흰 섬광·충격파 고리·파편 폭발·강한 흔들림 → 결과가 튕기듯 등장(등급색 광선, "등급 UP!"/"★ UP!", "희귀 → 영웅"/"★2 → ★3", 유물 ★ 하나씩 도장) →
  전설 이상·높은 ★는 색종이까지. 탭하면 다음 단계로 넘어가고, 여러 번 합성하면 [모두 건너뛰기]와 결과 모아 보기가 나옵니다.
- 상자 보상: 등급마다 보상이 1/2/3/4개입니다.
  - 첫 보상은 장비(확률 15/30/55/85%) 또는 높은 등급 스킬북이고, 나머지는 스킬북이나 강화석입니다.
  - 정산 때 열지 않은 상자는 자동으로 엽니다.
- 상인: 스킬북 2권이 주력 상품입니다. 원정에서는 챕터마다 6번째 무리에 나옵니다.
- 저장: `user://trio_save.json`에 `gold`, `stones`, `storage`, `loadout`, `slot_lv`, `run_gear`, `cleared`, `chapter`가 추가되었습니다.
  새 저장은 영웅마다 일반 무기 1개를 끼고 시작합니다.
- 확인용 인자:
  - `--mode=march --chapter=N --autoplay`: 원정 N 자동 진행. 자동 플레이는 스킬북을 쓰고 더 좋은 장비를 낍니다.
  - `--mode=march --test=books --shots=<폴더>`: 스킬북 가방 합성(일반 9권 → 영웅 1권 연쇄), 책 정보 창, 영웅 책 룰렛, 강제 전설 등장 연출, 칸 교체 창, 영웅 창, 상자 카드, 정산 창.
  - `--shots=<폴더> --open=gear`: 로비와 장비 화면 캡처 + 합성 연출 단계별 캡처(`merge_gear_*.png`).
  - `--shots=<폴더> --open=relic`: 유물 화면 + 유물 합성 연출 단계별·결과 모아 보기 캡처(`merge_relic_*.png`).
  - `--mode=march --test=relics --shots=<폴더>`: 판 중 장착 유물 목록, 유물 획득 → 로비 보관함 토스트.

## 말풍선 (잡담)
로비·클래식·행군의 모든 영웅과 몬스터가 이따금 작은 흰 말풍선으로 의성어나 아주 짧은 대사를 합니다(`scripts/chatter.gd`, 게임 판정과 무관한 순수 연출).
- 상황별 대사: 전투(`battle`), 체력 30% 미만(`low`), 행군 중 영웅(`march`), 모닥불 캠프(`camp`), 자는 중(`sleep`), 로비(`lobby`)
- 종류별 대사 표는 `Chatter.LINES`(예: 늑대 "아우우~!", 미믹 "와구와구", 심연의 군주 "무릎 꿇어라"), 공용 대사는 `Chatter.SHARED`
- 동시에 최대 3개, 새 말풍선 사이 최소 1.5초, 한 캐릭터는 8~22초에 한 번 정도. 말풍선은 글자가 다 보이는 상태로 3초간 유지되고(일시정지·팝업·히트스톱 중엔 시간이 멈춤), 말한 캐릭터가 죽으면 즉시 사라집니다. 화면 밖·팝업이 열린 동안·일시정지 중에는 말하지 않습니다.

## UI 프리셋 (뚜까펫 / 클래식)
로비 왼쪽 위 **[UI: 뚜까펫 ⇄ (F2)]** 버튼으로 UI 스타일을 바꿉니다. 누르면 바로 로비가 다시 그려지고, 선택은 `user://ui_preset.cfg`에 저장되어
다음에 들어가는 게임 화면(HUD·팝업·연출)에도 적용됩니다. 기존 Toy Clash 스타일은 **클래식** 프리셋으로 그대로 보존되어 있습니다.

    - 황혼 광산: 비계 탑, 도르래, 광차, 랜턴, 거대 분홍 버섯, 수정, 레일
    - 서리 봉우리: 눈 필드와 얼음 오솔길, 눈 덮인 침엽수, 얼음 가시, 눈사람, 설산
  - 새 지역에 들어서면 "새로운 지역 / 지역 이름" 배너만 뜨고 행군은 그대로 이어집니다(지도가 저절로 열리지 않음). 지역 칩에 빨간 "!" 배지가 붙고,
    다음에 직접 지도를 열면 해금 연출이 한 번 나옵니다: 방금 끝낸 지역에 "CLEAR!" 도장, 새 지역이 하얀 연기와 함께 회색→컬러로 바뀌며 이름표가 튀어나옵니다.
  - 우측 상단 크리스탈 아래 **지역 칩**(지도 아이콘 + 지역 이름 + 무리 n/10)을 탭해도 월드맵이 열립니다. 지도가 열린 동안 게임은 멈춥니다(X 또는 Esc로 닫기).
  - 열 때는 먼저 필드 카메라가 0.3초 동안 뒤·위로 빠지며 하늘 쪽으로 고개를 들고(줌아웃, 먼 땅은 하늘색 안개로 녹음), 닫을 때는 하늘에서 다시 내려옵니다.
  - 열고 닫을 때(약 0.66초): 평면 2D 구름이 왼쪽에서 오른쪽으로 빠르게 휩쓸며 구름 속에 들어갔다 나옵니다. 그림자 없이 층마다 한 가지 톤이고,
    뒤 층(라벤더 #d1d8f0) · 중간 층(연한 #eff1f9, 화면 아래쪽) · 앞 층(흰색, 화면 위쪽)이 같은 시간에 이동 거리가 크게 달라
    속도가 약 1 : 1.7 : 2.6으로 확연히 차이 납니다. 앞·중간 층은 길게 이어진 구름 열차라 많은 구름이 스칩니다.
    속도감 효과: 바람 선, 화면 렌즈 셰이더(가로 모션 블러, 볼록 왜곡, 색수차, 비네트)가 구름 속에서 가장 세집니다.
    구름 속에 잠긴 순간 필드와 지도가 바뀝니다(`cloud_fly.gd`).
  - 월드맵: 촛불이 켜진 책상 위 나무 액자 속 바다 지도를 아이소메트릭 느낌의 직교 카메라로 내려다보며, 현재 지역 쪽으로 줌인돼 열립니다(드래그로 이동).
    지나온 지역은 깃발 + CLEAR! 도장, 아직 못 간 지역은 회색조로 보이고, 항로가 지역을 잇습니다. 지역 이름은 "번호. 이름" 말풍선
    (완료=흰색+체크 방패, 현재=보라, 미해금=어두운 색)입니다. 지금 지역에는 무리 10개(처치=금색, 보스=해골)와 현재 위치에 선 3인방이 표시되고,
    아래 카드에 지역 이름·설명·진행도(무리 n/10, 중간 보스까지 남은 무리, 총 행군 거리, 다음 지역)가 나옵니다.
  - 확인용: `--mode=march --wave=24 --test=map --shots=<폴더>` (칩 탭으로 열기 → 닫기 → 해금 연출 재생 → 단계별 캡처 → 종료)
- 행군 중에는 영웅을 끌어 진형을 자유롭게 바꿀 수 있고(칸 스냅 없음), 장비 장착과 특성 구매도 됩니다.

## 조작
| 입력 | 동작 |
|---|---|
| 영웅 드래그 → 아래 4줄 칸 | 배치 / 자리 교환 (배치 단계) |
| 영웅 탭 | 상세 창: 능력치, 장비(칸 레벨), 배운 스킬 4칸 |
| 전투 시작! / `Space` | 웨이브 시작 |
| 전투 중 영웅 길게 누르기(0.3초) | 궁극기 조준 (전투 일시정지), 손을 떼면 발동 |
| 가방 아이템 탭 | 정보 카드 (사용·판매) |
| 가방 아이템 → 영웅(보드 또는 상세 창) 드래그 | 장착 |
| 판매 버튼 | 판매 모드 (탭하면 바로 판매) |
| 특성 버튼 | 영구 특성 트리 (시간의 결정 사용) |
| `Esc` | 팝업 닫기 / 종료 |

## 게임 흐름
배치 → 적 낙하 등장 → FIGHT! → 자유 이동 자동 전투 → 웨이브 클리어(시간의 결정 +2, 코인 회수, 회복, 시작 칸 복귀)
→ 3웨이브마다 특성 룰렛(자동 결정), 10웨이브마다 상인 → 다음 웨이브. 영웅 3명이 모두 쓰러지면 게임 오버.
처음 실행할 때만 튜토리얼 5단계가 나옵니다.

## 연출
- 궁극기: 전투가 잠깐(0.5초) 멈추고 얇은 레터박스 위쪽에 궁극기 이름이 뜨며 카메라가 시전자 쪽으로 살짝 다가갑니다. 무대 조명이 조금 어두워지고 스포트라이트를 받은 시전자가 기 모으는 포즈를 취합니다(멈춰 있던 다른 이펙트는 숨김). 재개 뒤 이펙트가 끝날 때까지 어두운 무대를 유지합니다(`cinematic.gd`).
- 고유 스킬: 짧은 히트스탑, 줌 킥, 섬광
- 장비를 끄는 동안: 어두운 무대 + 영웅 스포트라이트 + 레터박스(위 "끝없는 행군" 참고, 클래식도 같음)
- 마우스 오버한 영웅 / 장비를 끌어 올린 영웅: 커지면서 얇은 형광 노랑 외곽선이 생기고, 필드가 살짝 어두워지며 그 영웅만 조명을 받아 분리돼 보입니다(전투 중이라 장착할 수 없으면 빨간 외곽선)
- 아이템 드랍: 디아블로식으로 상자가 튀어나와 굴러 떨어진 뒤 등급 색 빛기둥과 이름표가 붙습니다. 웨이브가 끝나면 가방 칸으로 날아 들어갑니다(게임 오버 시 남은 드랍은 사라짐).
- 왼쪽 위: 영웅별 체력·마나·레벨·궁극기 준비 표시
- 아이템과 퍽 카드: 등급 색으로 패널 전체를 칠함. 가방 아이템에 마우스를 올리면 정보 카드, 누르면 고정(사용·판매 버튼)

## 사운드
배경음악은 `../tools/bgm_synth`의 스크립트가 numpy/scipy로 합성한 무이음새 루프입니다(샘플·외부 음원 없음). `--game`으로 다시 만들면 아래 파일이 덮어써집니다. 이음새가 샘플 단위로 이어지도록 PCM으로 임포트합니다(압축 없음, 루프 Forward).

| 곡 | 파일 | 생성 | 쓰는 곳 |
|---|---|---|---|
| battle | `audio/bgm_main.wav` | `synth_bgm.py --game` (120 BPM, 32초) | 클래식 디펜스 |
| field | `audio/bgm_field.wav` | `synth_bgm_field.py --game` (90 BPM, 43초) | 끝없는 행군 |
| lobby | `audio/bgm_lobby.wav` | `synth_bgm_calm.py --game` (72 BPM, 53초) | 로비 |
| gacha | `audio/bgm_gacha.wav` | `synth_bgm_gacha.py --game` (100 BPM, 38초) | 보물상자 화면 |

- 게임용 믹스는 효과음 대역을 비웠습니다. battle은 킥·베이스 저역, 리드, 하이햇을 줄이고 90 Hz·1.5 kHz를 깎았습니다. field는 플루트를 조금 줄이고 같은 두 대역을 깎았고, gacha는 셀레스타·글로켄을 줄이고 같은 두 대역과 3.2 kHz(sparkle)를 깎았고, lobby는 클릭·차임 자리인 1.2 kHz를 살짝 깎았습니다.
- `scripts/music.gd`(오토로드 `Music`): 로비는 `Music.play("lobby")`, 게임 씬은 `music_track()`(클래식 `battle`, 행군이 덮어써서 `field`)로 곡을 요청하면 1.2초 동안 equal-power 크로스페이드(중간에 음량이 꺼지지 않음)로 바뀝니다. 보물상자 화면을 열면 `gacha`로 1.8초 동안 넘어가고, 닫으면 필드 곡이 멈췄던 자리부터 다시 페이드인됩니다(`play(track, fade, true)`, 빠르게 오가면 페이드 도중에 방향만 바꿉니다). 같은 곡을 다시 요청하면 무시합니다. 곡별 음량 보정은 `TRACKS`에 있습니다(lobby -3 dB, gacha -1 dB). 버스는 코드로 만듭니다.
  - `Music` 버스 -12 dB. `SFX` 버스를 사이드체인으로 쓰는 컴프레서가 있어서 큰 타격음이 날 때만 음악이 2~6 dB 내려갑니다.
  - `SFX` 버스 -1.5 dB(`sfx.gd`의 모든 플레이어), `Master` 버스에 하드 리미터(-1 dB)
  - 게임 오버 징글이 단조라서, 그동안은 음악 버스를 -18 dB 더 낮춥니다(`Music.duck`).
  - 종료는 `Music.quit()`으로 합니다. 음악을 먼저 멈추고 0.12초 뒤에 종료해서 엔진 종료 누수 경고가 나지 않게 합니다.
- 믹스 측정: `../tools/bgm_synth/analyze_recording.py`에 Movie Maker 녹화(`--write-movie x.avi`)를 넣으면 실제 게임 출력의 음악·효과음 레벨과 이음새를 확인할 수 있습니다. 현재 값은 피크 -1 dBFS, 전투 중 효과음이 음악보다 약 8 dB 크고, 로비 음악은 약 -30 dBFS입니다.

## HTML과 다르게 한 것
- 외형·UI·이펙트는 전부 Toy Clash 스타일로 새로 만들었습니다(HTML 비주얼은 쓰지 않음).
- 이동은 칸 단위가 아니라 Toy Clash식 자유 이동입니다. 칸 규칙(맨해튼 사거리, 1칸 넉백, 관통 뒤 칸, 2×2 거인, 2칸 대시)은 연속 좌표로 바꿨습니다. 변환표는 계획서에 있습니다.
- 명백한 원본 버그는 고쳤습니다: 공격력 특성 2중 적용, 생명력 스킬의 최대 체력 초기화, 최대 체력 중복 표시, 환영 무적이 폭발·관통·번개에 안 먹던 문제, 실시간·게임 시간 혼용(궁극기 조준 중에는 모든 타이머가 멈춥니다), 튜토리얼 4단계에 기믹이 끼어들던 문제.
- 의도일 수 있는 동작은 원본대로 뒀습니다: 충격파 맵 전체 타격, 처치 시 마나 충전 장비가 아무 적 처치에나 반응, 심판의 번개는 보상 없음.
- 밸런스 조정(2026-10, 보고서 `docs/balance_report.html`):
  - 적 배율 `Defs.scaling(w) = 1.2 × 1.07^(w−1)`: 무리마다 같은 비율로 7%씩 강해집니다(지역당 ×1.97). 예전 곡선은 30무리까지 선형, 그 뒤 무리당 ×1.15라 원정 4~6챕터가 벽이었습니다.
  - 메이지 볼트 2발은 각각 온전한 타격의 60%(`Combat.BOLT_MULT`). 예전엔 DPS가 워리어의 3.3배였습니다.
  - 받는 피해 감소 상한 90% → 75%(`Stats.CAP_REDUCE`), 유물 ★당 +40% → +25%, 흡혈 상한 35%.
  - 슬롯 강화 강화석 비용 `2 + lv×0.8` → `2 + lv×0.5`.
  - 미구현이던 특성 구현: 약점 추적(레인저 보스·정예·환술사 피해 +5%/Lv), 냉기 숙련(메이지 빙결 확률 +5%/Lv).
- 궁극기 쿨타임은 전투 시간 기준으로만 흐릅니다.
- 튜토리얼을 끝내면 저장되어 다시 나오지 않습니다(HTML은 페이지를 열 때마다 나옴).

## 디버그 메뉴
전투 화면 왼쪽, 영웅 표시 아래의 작은 **DBG** 버튼을 누르면 디버그 퀵버튼 목록이 펼쳐집니다(`scripts/debug_hud.gd`, 새 기능은 `ACTIONS`에 추가).
- **아이템 획득 연출**: 무작위 장비 하나가 영웅들 앞 필드에 떨어졌다가(상자·빛기둥·이름표) 1.3초 뒤 가방으로 날아 들어갑니다. 확인용: `--mode=march --test=debug`

## 개발용 인자 (`--` 뒤에 붙임)
- `--autoplay`: 자동 진행(배치·전투·퍽·상인 자동 처리)
- `--shots=<dir>`: 주요 순간을 PNG로 저장
- `--quit=<초>`, `--seed=<n>`, `--wave=<n>`(시작 웨이브), `--gimmick=<이름>`(기믹 강제)
- `--test=panel|aim|items|perks|talents|gimmick|tutorial`: 화면별 스크립트 검증
- `--mode=classic|march`: 로비를 건너뛰고 바로 모드 진입 (`--autoplay`/`--test`만 주면 클래식으로 진입)
- `--mode=march --test=camp`: 적 캠프 대기 연출 스크린샷
- `--mode=march --test=notice`: 장비 드래그 슬로우모션·영웅 줌인, 필드 아이템 이름표 정렬(겹침 없음) + 중앙 알림 띠(기믹 문구 + 토스트 최대 2개, 밀어내기) 검증
- `--mode=march --test=pause`: 아이템 정보·영웅 정보창이 열려 있는 동안 행군·전투 정지, 닫으면 재개 검증
- `--mode=march --test=ui`: 장비 드래그 슬로우모션·전투 중 장착·얼굴 탭 정보창 검증
- 자동 진행·테스트 모드는 별도 저장 파일(`user://trio_save_test.json`)을 씁니다.
