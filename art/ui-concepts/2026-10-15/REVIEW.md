# 산출물 검수

- 대표 화면 3개: 로비, 전투 HUD, 장비·보관함. 선정 이유와 원본 캡처는 README 및 갤러리에 포함.
- 스타일 3개: 토이 팝 / 모험수첩 / 나이트 아케이드.
- 각 보드는 로비 → 전투 → 장비의 3화면으로 구성. 총 9개 화면 시안.
- 최종 보드 3개를 직접 시각 검수. 각각 1536×1024 PNG.
- 실제 브라우저에서 A/B/C 전환, 전체 비교, 현재 화면, 확대 보기 및 닫기 확인.
- 전체 비교 DOM에서 최종 PNG 3개 모두 complete=true, naturalWidth=1536, naturalHeight=1024 확인.
- 갤러리 인라인 JavaScript와 미리보기 서버의 문법 검사 통과.
- 생성 이미지의 세부 한글·수치·슬롯 수는 구현 명세가 아니다. 검수 메모와 갤러리에 해당 범위를 표기.
- 최종 추천은 A. 게임 코드 적용은 이 작업의 범위에 포함하지 않음.
