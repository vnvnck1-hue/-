# 검수 기록

- D/E/F 각 로비·전투·장비 3화면, 총 9화면. 최종 PNG 3개를 직접 시각 검수했다.
- 이전 C안의 직업명·큰 초상화·여러 줄 스탯을 가진 영웅 카드를 제거했다. 스킬 6개와 작은 얼굴·HP·마나·레벨의 캡슐 3개로 구성한다.
- 원본 코드의 지름 58 / 상태줄 높이 46을 프롬프트와 적용 규격의 기준으로 기록했다. 생성 시안의 픽셀 좌표·아이콘 크기에는 오차가 있으므로, 실제 적용 때는 이 원본 규격을 고정해야 한다.
- 최종 파일: `d-ink-mint.png`, `e-graphic-violet.png`, `f-midnight-brass.png`. 모두 1536×1024.
- 브라우저에서 D/E/F 전환과 전체 비교를 확인했다. 최종 이미지 3개 모두 complete=true / naturalWidth=1536 / naturalHeight=1024 확인.
- 원본 비교 이미지 3개 모두 complete=true / 540×960 확인.
- 갤러리 JavaScript 문법 검사 통과.
- 연구는 공식 스토어 이미지, 공식 업데이트 및 2026 디자인 분석을 구분해 기록했다. 어두운 색을 시장 전체의 유행으로 단정하지 않았다.
- 게임 코드 수정 없음. 최종 비교 페이지는 D안을 선택한 상태로 열어 두었다.
