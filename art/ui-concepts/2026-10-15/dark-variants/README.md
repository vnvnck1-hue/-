# 어두운 UI 변형 3종

사용자가 선택한 C · 나이트 아케이드에서 D/E/F 세 방향으로 확장한다. 대표 화면은 기존과 같은 로비 / 전투 / 장비·보관함, 총 9개 화면이다.

## 가장 중요한 수정

이전 C 시안의 두꺼운 영웅 카드·큰 스킬 버튼을 사용하지 않는다. 기존 게임의 스킬 원 6개와 한 줄 상태 캡슐 3개를 위치와 높이의 기준으로 삼는다. HP·마나·작은 초상화·레벨 외에 직업명, 큰 숫자, 추가 줄은 넣지 않는다.

720×1280 기준: 스킬 원 지름 58 / 스킬 행 높이 64 / 영웅 상태줄 높이 46 / 두 행이 차지하는 전체 구간 높이 116. 이전 C안의 큰 카드와 다르게 스킬은 필드 위에 가볍게 놓는다.

## 스타일

| 방향 | 바탕·강조 | 구분점 |
|---|---|---|
| D · 잉크 민트 (추천) | 무광 남색·민트 | 가는 선, 평평한 표면, 얇은 둥근 프레임 |
| E · 그래픽 바이올렛 | 흑보라·라일락·소량의 라임 | 잘린 모서리, 굵은 제목, 그래픽 탭 |
| F · 미드나이트 브라스 | 따뜻한 차콜·황동 | 얕은 에나멜, 부드러운 웜톤 강조 |

색·재질 차이는 주로 로비와 장비 화면에서 표현한다. 전투 화면에서는 같은 가는 정보 구조를 유지한다. 캐릭터와 밝은 필드의 정체성은 그대로 둔다.

## 파일

- `index.html`: 세 변형 비교와 원본 보기, 확대 보기.
- `concepts/d-ink-mint.png`, `concepts/e-graphic-violet.png`, `concepts/f-midnight-brass.png`: 최종 보드.
- `RESEARCH.md`: 공식 사례·디자인 분석 출처, 관찰과 적용 해석, 기존 UI 규격.
- `prompts.json`: 내장 image_gen에 사용한 전체 프롬프트.
- `refinements.json`: 스킬·상태줄의 크기와 위치를 정리한 후속 이미지 편집 프롬프트.
- 원본 게임 캡처는 상위 폴더 `references/`를 사용한다.

생성 이미지로 제작한 아트 디렉션 시안이다. 픽셀 단위 구현 원본은 아니며 세부 한글·수치·슬롯 수는 적용 단계에서 정리한다. 게임 코드는 수정하지 않는다.
