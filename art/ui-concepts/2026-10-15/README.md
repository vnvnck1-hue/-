# TRIO CHESS UI 스타일 탐색 · 2026-10-15

현재 실행 파일의 화면을 직접 캡처한 뒤, **동일한 대표 화면 3개 × 스타일 3종 = 9개 화면 시안**으로 비교한다. 게임 적용 전의 아트 디렉션 제안이다.

## 대표 화면 선정

| 화면 | 선정 이유 | 이번 시안의 핵심 |
|---|---|---|
| 로비 | 첫인상과 주요 플레이 진입 동선 | 3인 파티를 주인공으로 두고 원정 출발을 가장 강하게 표시. 보조 콘텐츠와 수령 알림의 시각적 무게를 줄임. |
| 전투 HUD | 가장 오래 보는 화면, 실시간 판단과 조작 | 필드를 넓게 확보. 무리 진행 → 스킬 준비 → 3인 상태 → 가방의 정보 층위 구분. |
| 장비·보관함 | 높은 정보 밀도와 반복 성장 동선 | 직업 선택 → 착용 장비·칸 강화 → 보관함 → 선택 아이템 상세·장착 순서. |

기준 캡처: `references/lobby.png`, `references/w02_07_battle.png`, `references/gear.png`. 실행 파일을 테스트 저장으로 구동해 촬영했다. 장비 촬영용 테스트 아이템이 포함된 상태다.

## 3가지 방향

| | A · 토이 팝 (추천) | B · 모험수첩 | C · 나이트 아케이드 |
|---|---|---|---|
| 인상 | 밝고 경쾌한 장난감 패키지 | 따뜻하고 차분한 원정 기록 | 선명하고 정돈된 전략 아케이드 |
| 바탕 | 아이보리 `#FFF5DD` | 종이 `#F3E7CB` | 잉크 남색 `#191D35` |
| 글자·윤곽 | 네이비 `#243047` | 짙은 갈색 `#463B30` | 밝은 흰색 `#F3F4FF` |
| 주 행동 | 노랑 `#FFD34D` | 숲 초록 `#294D46` | 민트 `#70E1C6` |
| 보조 | 코랄·청록 | 세이지·황동 | 라일락·코랄 |
| 형태 | 둥근 카드, 얕은 입체 턱 | 북마크 탭, 얇은 인쇄선 | 정밀한 모듈, 얇은 키라인 |
| 주의점 | 모든 버튼을 입체·고채도로 만들지 않기 | 종이 질감·장식을 정보 위에 얹지 않기 | 네온·어두운 패널이 필드를 압도하지 않기 |
| 현재 아트와의 관계 | 밝은 로우폴리 캐릭터와 가장 자연스러움 | 모닥불·원정 분위기를 강조 | 밝은 필드와 어두운 HUD의 대비 강조 |

**추천: A.** 이미 있는 밝은 3D 월드와 장비 아이콘을 살리면서, UI의 위계와 일관성을 개선하기 가장 자연스럽다. B는 원정의 정서, C는 전투 정보의 선명함을 브랜드 중심에 두고 싶을 때 적합하다.

## 공통 규칙 제안

- 기준 화면 비율은 9:16. 현재 논리 뷰포트는 720×1280, 캡처는 540×960이다.
- 3D 캐릭터·필드 정체성과 기존 콘텐츠를 유지한다. 스타일 비교에서 월드까지 바꾸지 않는다.
- 체력은 초록, 마나는 파랑. 영웅 구분은 워리어 코랄 / 레인저 초록 / 메이지 보라.
- 희귀도는 파랑·보라·금색으로 통일한다. 선택 표시는 별도 체크/윤곽을 사용해 희귀도와 구분한다.
- 로비는 원정 출발을 주 행동으로, 끝없는 행군을 보조 진입으로 둔다. 수령 알림은 작은 배지로 정리한다.
- 전투의 가운데 필드는 화면 높이의 절반 이상을 목표로 한다. 준비된 스킬만 강조한다.
- 장비의 강화 비용은 각 장비 칸 아래에 모으고, 장착·판매는 선택 아이템 상세에 붙인다.
- 주요 터치 영역은 360 CSS px 폭 기준 최소 44px 높이를 목표로 한다(720 논리 폭에서는 약 88 단위). 색 이외에 문자·아이콘으로도 상태를 전달한다.

위 수치와 대비는 적용 단계의 검증 목표다. 생성 이미지가 실제 픽셀 규격·접근성 검증을 통과했다는 의미는 아니다.

## 산출물

- `index.html`: 세 스타일 전환, 전체 비교, 원본 화면, 큰 이미지 보기.
- `concepts/a-toy-pop.png`: A의 로비 / 전투 / 장비.
- `concepts/b-field-journal.png`: B의 로비 / 전투 / 장비.
- `concepts/c-night-arcade.png`: C의 로비 / 전투 / 장비.
- `prompts.json`: 사용한 전체 프롬프트. 내장 `image_gen`으로 제작.
- `refinements.json`: C안의 개발용 표시·직업명·아이템 수치 정리용 후속 편집 프롬프트.

`index.html`은 파일을 직접 열어도 작동한다. 앱 브라우저용 로컬 미리보기를 다시 띄우려면 이 폴더에서 `node preview.cjs` 실행 후 `http://127.0.0.1:8137`에 접속한다.

기존 게임 코드는 수정하지 않았다. 이미지는 분위기·컴포넌트·배치 방향을 평가하는 시안이며, 세부 수치·한글 본문·정확한 슬롯 수는 구현용 원본으로 사용하기 전에 정리해야 한다. 비교를 위해 시안의 재화 수치는 통일했다. 신규 게임 기능은 제안 범위에 넣지 않았다.
