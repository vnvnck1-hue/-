# 최종 검토 · 2026-10-23

## 요청별 확인

- 현재 로비: 최신 루트 실행 파일의 내장 캡처를 `lobby.png`로 저장하고 직접 확인했다. 실제 기능은 로비 스크립트와 대조했다.
- 리서치 선행: 공식 스튜디오·스토어·업데이트와 공개 플레이 화면을 조사한 뒤 `RESEARCH.md`와 세 프롬프트를 먼저 작성했다. 이후 이미지를 생성했다.
- 회사 범위: Supercell / Supercent / Voodoo / Gorilla Studio 계열. 총 6개 게임의 화면 구조나 조형을 비교했다.
- 최신성: 2026년 공식 서비스 자료와 현재 스토어를 확인했다. 과거 캡처는 캡처 날짜/확인 한계를 표시했고, 최신 바이너리의 전체 로비라고 표현하지 않았다.
- A: 큰 파티·캠프와 하단 출발 시트. 원정 선택, 보조 행군, 장비·유물·캠프·도전·성장, 미션·출석·캠프 보상이 보인다. 첫 결과의 과도한 빨간 점 2개를 삭제하는 후속 편집을 거쳤다. 최종 빨간 점은 장비와 캠프 보상 두 곳이다.
- B: 세 섬과 수직 경로, 현재 지역과 잠긴 다음 지역, 고정 출발 도크. 세 영웅·재화·미션·출석·보상과 하단 기능이 보인다. 행군·토벌은 도전 탭 아래로 설계했다.
- C: 세 영웅의 큰 카드 3개, 작은 모닥불 보상 줄, 원정/행군 모드 타일, 단일 출발 버튼. 기존 영웅 카드 탭은 장비 화면 진입으로 설계했으며 신규 출전 선택 시스템은 가정하지 않았다.
- 세 이미지 모두 직접 시각 검토했다. 한 장에 단일 세로 게임 화면이며, 서로 다른 레이아웃이고 기기 목업·콜라주·개발용 버튼이 없다. 공통 재화 47,769 / 986 / 1,698과 세 캐릭터의 색·장비 정체성을 확인했다.
- 최종 이미지 각 941 × 1672 PNG. 워크스페이스 복사본과 생성 원본의 바이트 동일성을 검사하고 해시를 `manifest.json`에 기록했다.
- 프롬프트 JSON 구문 및 갤러리의 이미지·문서 참조 파일 존재를 확인했다. 이 환경의 앱 브라우저는 localhost 연결에 실패했으므로 갤러리의 브라우저 실행 검증 완료를 주장하지 않는다. 개별 PNG 시각 검토와 파일 검증은 완료했다.

## 사용 범위

구현용 UI 파일이 아닌 래스터 컨셉이다. 실제 터치 영역, 폰트 대비, 안전 영역, 잠금·선택·수령 상태 및 애니메이션은 게임 적용 단계에서 검증해야 한다. 게임 소스·실행 파일은 변경하지 않았다.
